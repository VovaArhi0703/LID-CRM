# LID CRM — тарифы и настройка подписки

Готовый интерактивный фронтенд двух экранов по исходным JSON из Figma. Работает локально без сервера API, без внешних CDN и без установки npm-зависимостей. Исходные файлы сохранены в `reference/`.

## Запуск

1. Установите **Node.js 18+**.
2. Откройте терминал в этой папке проекта.
3. Выполните `npm start`.
4. Откройте **http://127.0.0.1:4173**.

В Windows можно дважды нажать `start.cmd`. Для статического развёртывания: `npm run build` — готовые файлы появятся в `dist/`; загрузите **содержимое `dist/`** на любой статический хостинг. Приложение также рассчитано на локальное открытие `index.html` в браузере.

## Поведение

- Первый экран: три тарифные карточки, выбор срока **1 / 6 / 12+1 месяцев**, тарифные цены для каждого срока и бонусная надпись для 12 месяцев. Кнопка тарифной карточки открывает настройки **того же тарифа и выбранного срока**. При наведении мыши карточка поднимается на **5 px**, а скрытое изначально фиолетовое свечение из **четырёх угловых градиентов Figma** анимируется **1 секунду** от `0,72°` до `142,47°`. Отдельная полоса цвета фона перекрывает свечение, начиная на **76 px ниже карточки** (координата `y=899` в исходном макете). После ухода курсора свечение исчезает.
- Второй экран: изначально пустые поля имени, описания, категории, клиента и комментария; валюта — **RUB**, сотрудники — **1**, воронки — **1**; дата начала — **сегодня по часовому поясу браузера**, триал — **3 дня**, выбранный срок унаследован с первого экрана.
- Период синхронизирован между двумя экранами, также при возвращении назад к тарифам.
- Дата окончания **только для чтения** и вычисляется из даты начала, оплаченного периода, дополнительного подарочного месяца для годовой подписки и трёх дней триала.
- Списки категории и клиента и календарь находятся **в потоке документа**, поэтому при раскрытии сдвигают содержимое формы, не перекрывают следующие поля и остаются привязанными к родительскому элементу при прокрутке. В поле клиента можно вводить часть названия, выбирать совпадения или раскрывать полный список отдельной стрелкой. В вариантах с активными подписками соответствующее количество подсвечено фиолетовым. Ввод неизвестного аккаунта не проходит валидацию.
- Описание и комментарий автоматически растут вниз при наборе текста.
- Дополнительные модули включаются независимо, суммы и скидки пересчитываются при каждом изменении.
- Обязательные поля, числовые ограничения, ошибки, состояния кнопок, клавиатурная навигация и закрытие окна по Escape/клику за пределами окна обработаны.
- «Перейти к оплате» в демонстрационном режиме **не списывает деньги**. После проверки полей настройки закрываются, а по центру показывается шуточное сообщение. Кнопка «Спасибо, хорошо» возвращает к тарифам; данные заказа сохраняются только локально в `localStorage`.

## Цены и расчёты

База за пользователя в месяц: **790 / 1 490 / 2 490 ₽** для тарифов Стандарт / Плюс / Премиум. Срок **6 месяцев** — скидка **5%**, **12 месяцев** — скидка **10%** и ещё **один месяц доступа бесплатно**. Отображаемая цена на карточках округлена до рубля: **751 / 1 416 / 2 366 ₽** (6 мес.) и **711 / 1 341 / 2 241 ₽** (12 мес.). Для итогового расчёта используется **неокруглённая** ставка, поэтому не накапливается ошибка округления.

В демо реализован пример расчёта из переписки: **5 сотрудников, Плюс, 6 месяцев, 3 модуля, клиент с 3% скидкой:** лицензии 44 700 ₽ + модули 32 100 ₽ − скидка срока 3 840 ₽ − скидка клиента 2 188,80 ₽ = **70 771,20 ₽** (на экране **70 771 ₽**).

**Важно:** исходные макеты не задают правила получения живых валютных курсов, реального статуса скидки клиента и проведения оплаты. Для демонстрации используются фиксированные курсы **1 RUB = 0,01 USD = 0,0092 EUR**, а клиент получает **3%** после скидки за срок, если у выбранного аккаунта уже есть хотя бы одна активная подписка. В демо это «Грейд», «Пиксель» и «Орбита» (аккаунт «Пульс» скидку не получает). Эти параметры находятся в `src/calculator.js`, расчёт является образцом и должен быть согласован с будущим бэкендом перед запуском платёжной системы. Курс и скидка не выдаются за фактические рыночные данные.

## Файлы проекта

- `src/app.js` — два экрана, состояние, события, расчётная панель и модальное окно.
- `src/components.js` — общие кнопки, текстовые поля, селекты, степперы, группы выбора и календарь.
- `src/calculator.js` — отделённая от UI логика цен, скидок, дат и валидации.
- `src/styles.css` — типографика, отступы, размеры, цвета, интерактивные состояния и адаптивность.
- `assets/icons/*.svg` — **41 отдельный уникальный SVG**, экспортированный из векторных путей переданных JSON. Дубликаты SVG дедуплицированы без подмены контуров. Полная карта **515 соответствий идентификаторов слоя к файлу** находится в `docs/asset-manifest.json`.
- `assets/fonts/Manrope-Variable.ttf` — локальный Manrope (лицензия `assets/fonts/OFL.txt`), `assets/avatar.jpg` — аватар из присланного проекта.
- `reference/1.json`, `reference/2.json`, `reference/3.json` — исходные макеты и компонентная библиотека. `reference/1.1.json` — обновлённый вариант первого экрана с тремя включёнными в JSON слоями Card Glow; **в живом интерфейсе** они по умолчанию скрыты и проявляются только при наведении.
- `src/design-data.js`, `src/renderer.js` — слой исходных Figma-данных и рендерер просмотра вариантов компонентов (`#components`), не подменяющий рабочие HTML-контролы.
- `docs/previews/` — скриншоты браузерной проверки.

## Проверки

`npm test` — **17 наборов тестов** (все 9 цен, формулы, даты и високосные годы, обязательные поля, валюты, иконки и шрифты). Дополнительно `python scripts/qa_browser.py` — **50 интерактивных проверок браузера Chromium**, включая раскрытие списков, перерасчёты, триал, валидацию и ширины 320, 390, 760, 1280, 1920 px. Дополнительно `python scripts/qa_account.py` — **24 проверки** поля клиента, поиска, стрелки, ошибок и скидок. `python scripts/test_glow.py` проверяет **анимацию градиента во времени**, 4 слоя на карточку, подъём, фоновые маски, скрытое состояние, уход курсора и адаптивность; контрольные кадры находятся в `docs/previews/glow-*.png`. Для необязательных браузерных тестов нужны Python 3, Playwright и Chromium; для работы самого сайта они **не нужны**. Подробнее: `docs/VERIFICATION.md`.

### Ограничения восстановления

SVG были извлечены из предоставленных векторных путей, а не заменены похожими значками; пустых векторных путей в этих JSON нет. Единственное растровое изображение в JSON ссылается на хеш Figma, поэтому используется предоставленный вместе с ZIP `assets/avatar.jpg`. Исходный Figma-файл и прямой экспорт PNG экрана не предоставлены: сверка геометрии проведена по данным JSON и браузерным скриншотам, а не по пиксельному наложению с оригинальной Figma-картинкой. Неописанные в JSON бизнес-правила помечены как демонстрационные.
